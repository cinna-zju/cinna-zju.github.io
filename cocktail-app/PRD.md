# 鸡尾酒应用 - 产品需求文档（PRD）

## 1. 项目概述

### 1.1 产品定位
一个精美的鸡尾酒百科应用，为调酒爱好者和专业人士提供经典鸡尾酒的完整信息，包括配方、调制方法、历史背景等。

### 1.2 目标用户
- 鸡尾酒爱好者
- 吧台调酒师
- 酒类学习者
- 派对组织者

### 1.3 核心价值
- 快速查询经典鸡尾酒配方
- 了解鸡尾酒文化和历史
- 可视化学习调酒步骤

## 3. 数据结构设计

### 3.1 鸡尾酒数据模型
```json
{
  "id": "string",
  "name": "string",
  "nameEn": "string",
  "image": "string",
  "category": "string",
  "glassType": "string",
  "alcoholContent": "number",
  "flavor": ["string"],
  "baseSpirit": "string",
  "ingredients": [
    {
      "name": "string",
      "amount": "string",
      "unit": "string"
    }
  ],
  "garnish": "string",
  "preparation": ["string"],
  "history": "string",
  "difficulty": "string",
  "tags": ["string"]
}
```

### 3.2 字段说明
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 唯一标识符（kebab-case） |
| name | string | 是 | 中文名称 |
| nameEn | string | 是 | 英文名称 |
| image | string | 是 | 图片文件名 |
| category | string | 是 | 分类（经典/现代/热带等） |
| glassType | string | 是 | 杯型 |
| alcoholContent | number | 是 | 酒精度（百分比） |
| flavor | array | 是 | 风味标签数组 |
| baseSpirit | string | 是 | 基酒类型 |
| ingredients | array | 是 | 配方材料列表 |
| garnish | string | 是 | 装饰物 |
| preparation | array | 是 | 调制步骤 |
| history | string | 是 | 背景故事 |
| difficulty | string | 是 | 难度（简单/中等/困难） |
| tags | array | 否 | 额外标签 |

### 3.3 筛选维度
- **基酒类型**: 伏特加、金酒、朗姆酒、威士忌、龙舌兰、白兰地、利口酒
- **风味类型**: 清爽、果味、甜味、酸味、苦味、香料、奶油
- **酒精度**: 低（<15%）、中（15-25%）、高（>25%）
- **难度**: 简单、中等、困难
- **分类**: 经典、现代、热带、冬季

## 4. UI/UX 设计规范

### 4.1 设计风格
- **风格**: 现代简约，带有一丝复古优雅
- **主色调**: 深琥珀色 (#D4A574) + 深色背景 (#1A1A2E)
- **辅助色**: 金色 (#C9A227)、深红 (#8B0000)

```css

  /* 背景色 */

  --color-text-light: #FFFFFF;

  /* 强调色 */
  --color-accent-gold: #C9A227;

  /* 分类色 */
  --color-vodka: #E0E5EC;
  --color-gin: #A8D8EA;
  --color-rum: #D4A574;
  --color-whiskey: #C9A227;
  --color-tequila: #98D8C8;
  --color-brandy: #8B4513;
  --color-liqueur: #FF69B4;

```

### 4.3 布局规范
- **容器最大宽度**: 1200px
- **卡片间距**: 24px
- **内边距**: 16px / 24px
- **圆角**: 12px（卡片）、8px（按钮）
- **阴影**: 0 4px 20px rgba(0,0,0,0.3)

### 4.4 响应式断点
- **移动端**: < 768px（单列）
- **平板**: 768px - 1024px（双列）
- **桌面**: > 1024px（三列）

### 4.5 动画效果
- **卡片悬停**: scale(1.02) + 阴影加深
- **页面过渡**: fadeIn 0.3s ease
- **调酒步骤**: 逐步骤动画，带进度指示

## 5. 功能需求详细说明

### 5.1 首页 - 鸡尾酒列表
**功能**:
- 网格布局展示所有鸡尾酒卡片
- 每张卡片显示：图片、名称、基酒、酒精度、风味标签
- 点击卡片进入详情页

**UI组件**:
- 顶部搜索栏
- 筛选器（基酒、风味、酒精度）
- 排序选项（名称、酒精度、难度）
- 鸡尾酒卡片网格

### 5.2 搜索与筛选
**功能**:
- 实时搜索（输入时即时过滤）
- 多条件筛选（可组合）
- 筛选结果计数
- 清除筛选按钮

**筛选器设计**:
- 基酒：复选框组
- 风味：标签云（可多选）
- 酒精度：滑块或范围选择
- 难度：单选按钮

### 5.3 详情页
**布局**:
```
┌─────────────────────────────────────┐
│           鸡尾酒大图                 │
├─────────────────────────────────────┤
│  名称 | 酒精度 | 难度 | 杯型        │
├─────────────────────────────────────┤
│  风味标签                           │
├─────────────────────────────────────┤
│  配方材料表                         │
├─────────────────────────────────────┤
│  装饰物                             │
├─────────────────────────────────────┤
│  调制步骤（带动画）                  │
├─────────────────────────────────────┤
│  背景故事                           │
└─────────────────────────────────────┘
```

**交互**:
- 点击步骤播放动画
- 返回按钮
- 分享按钮（可选）

### 5.4 调酒步骤动画
**动画流程**:
1. 步骤指示器显示当前步骤
2. 点击"下一步"或自动播放
3. 每个步骤显示：
   - 步骤序号
   - 操作说明
   - 相关材料高亮
   - 简单动画效果（如倒入、摇晃图标）

**动画类型**:
- 倒入：液体流动效果
- 摇晃：容器晃动效果
- 搅拌：旋转效果
- 装饰：放置装饰物效果
